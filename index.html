      Your first search, step by step

      Follow a real NFCorpus search from choosing a collection to reading the original article. No model download needed.

      1. 01

        Choose and prepare a collection

        One-time setup

        In Chat, select NFCorpus and click Prepare NFCorpus. Wait for Ready to search. The collection and its index are saved in this browser for next time.

        Collection settings: NFCorpus · MS MARCO (general web passages · 3.35 GB).

      2. 02

        Enter your search and send

        Open Chat, type coffee blood pressure, and press Enter or click the Send arrow. Start with keywords when searching without the optional answer model.

        Behind this search: DuckDB searches your saved index on your device. BM25 ranks the keyword matches and returns up to ten source documents automatically.

      3. 03

        Open Sources and check the evidence

        Expand Sources beneath the reply to see the matching articles. Open Full document text on an article to read beyond the excerpt.

      Want a written answer, too?

      Optional

      On a supported GPU, add the local model in Model settings (~1.84 GB). It writes answers from your sources and supports contextual follow-ups. Select a citation to jump to its evidence. Search works without it.

      How it works

      A question becomes keywords.

      BM25, DuckDB’s full-text ranking method, weighs:

      • Word rarity

        Distinctive terms carry more weight.

      • Word frequency

        Repeated matches help, with diminishing returns.

      • Document length

        Length is factored into the score.

      Scores measure relevance to a query, not factual accuracy.

      NFCorpus search SQL 
      SELECT id, title, text,
       fts_main_nfcorpus.match_bm25(id, ?) AS score
FROM nfcorpus
WHERE score IS NOT NULL
ORDER BY score DESC, id
LIMIT 10;

      The ? is a bound parameter containing the normalized search text.

      How it runs on your device

      A web worker runs code in the background. The chat page sends work to these workers and displays their results, keeping the interface responsive.

      The browser downloads engine code, extensions, collections, and optional model files. Startup may still need network access on later visits.
